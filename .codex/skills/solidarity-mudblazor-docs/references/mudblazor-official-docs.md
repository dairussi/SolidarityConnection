# MudBlazor official docs

Use the official MudBlazor site first.

## Primary URLs

- Docs home: https://www.mudblazor.com/
- Installation: https://www.mudblazor.com/getting-started/installation
- Components index: https://www.mudblazor.com/components
- Button: https://www.mudblazor.com/components/button

- Dialog: https://www.mudblazor.com/components/dialog

- Paper: https://www.mudblazor.com/components/paper
- Stack: https://www.mudblazor.com/components/stack

## How to use the docs

- Open the closest component page first.
- Copy the pattern conceptually, then adapt names, props, validation, and classes to the repo.
- Use the live examples and API tables to confirm parameter names before coding.
- If a component page is not obvious, start from the components index and then narrow down.

## Search hints

- Search: `site:mudblazor.com/components MudBlazor <component-name>`
- Search: `site:mudblazor.com/getting-started MudBlazor <topic>`
- Search: `site:mudblazor.com MudBlazor <component-name> api`
